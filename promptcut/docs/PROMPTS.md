# Sample Prompts for PromptCut

This document contains sample prompts you can use to edit videos with PromptCut.

## Quick Edits

### Simple Cuts
```
Cut all clips to 5 seconds each
```

### Montage Creation
```
Create a 30-second montage with quick cuts
```

### Reordering
```
Reverse the order of all clips
```

## Style-Based Prompts

### Cinematic
```
Make it cinematic with slow crossfades and dramatic pacing
```

### Fast-Paced
```
Create a high-energy edit with cuts every 2 seconds
```

### Documentary Style
```
Documentary style with talking heads and b-roll cutaways, add subtle transitions
```

### Music Video
```
Create a music video edit with beat-synced cuts and visual effects
```

## Complex Story Structures

### Three-Act Structure
```
Create a 90-second story: 10s hook intro, 70s development with rising action, 10s emotional conclusion with fade to black
```

### Hero's Journey
```
Tell a hero's journey: setup (15s), challenge (30s), transformation (30s), resolution (15s)
```

### Before/After
```
Create a before/after transformation video: show the problem (20s), the solution (40s), the results (30s)
```

## Technical Prompts

### Transitions
```
Add crossfade transitions between all clips, 1 second duration
```

### Speed Ramping
```
Apply slow motion to the first 3 clips and speed up the last 2 clips
```

### Color Grading
```
Add a warm, golden color grade to create a nostalgic feeling
```

### Text Overlays
```
Add captions for each speaker with their name and title
```

## Event-Specific Prompts

### Wedding Video
```
Create a romantic wedding highlight: ceremony entrance (10s), vows (20s), kiss (5s), reception dancing (25s), exit (10s) with romantic music and slow crossfades
```

### Sports Highlight
```
Make an energetic sports highlight reel with speed ramps on key moments, fast cuts between plays, and dramatic slow motion on scoring moments
```

### Travel Vlog
```
Create a travel montage: establish location (5s), explore scenes (40s), local culture (30s), sunset conclusion (10s) with upbeat pacing
```

### Product Demo
```
Professional product demo: intro with logo (3s), problem statement (10s), product features (40s), call to action (7s)
```

### Tutorial
```
Step-by-step tutorial format: intro (5s), step 1 with title card (20s), step 2 (20s), step 3 (20s), recap (10s)
```

## Advanced Prompts

### Multi-Camera Edit
```
Create a multi-camera interview edit: switch between wide and close-up angles every 10-15 seconds, use the close-up for emotional moments
```

### B-Roll Integration
```
Main interview clips with b-roll overlays: show speaker for 10s, cut to relevant b-roll for 5s, repeat throughout
```

### Emotional Arc
```
Build an emotional journey: start calm (20s), build tension (30s), climax (15s), resolution (20s) using pacing and music
```

### Commercial Format
```
30-second commercial: attention-grabbing hook (3s), problem (7s), solution (15s), call to action with logo (5s)
```

## Tips for Writing Good Prompts

1. **Be Specific**: Instead of "make it better", say "add crossfade transitions and increase pacing"
2. **Include Duration**: Specify target length like "60-second video" or "2-minute film"
3. **Describe Mood**: Use words like "dramatic", "upbeat", "calm", "energetic"
4. **Mention Structure**: Reference intro/middle/outro or specific acts
5. **Specify Techniques**: Name transitions, effects, or editing styles
6. **Think Like an Editor**: Consider pacing, rhythm, and story flow

## Prompt Templates

### Template 1: Duration + Style + Structure
```
Create a [DURATION] [STYLE] video with [STRUCTURE]
Example: Create a 60-second cinematic video with a clear intro, development, and conclusion
```

### Template 2: Story + Pacing + Effects
```
Tell a story about [TOPIC] with [PACING] and [EFFECTS]
Example: Tell a story about transformation with fast-paced cuts and crossfade transitions
```

### Template 3: Purpose + Audience + Tone
```
Make a [PURPOSE] video for [AUDIENCE] with a [TONE] feel
Example: Make a promotional video for social media with an energetic feel
```

## Combining Prompts

You can refine edits with sequential prompts:

1. First prompt: "Create a 60-second montage"
2. Second prompt: "Add crossfade transitions"
3. Third prompt: "Speed up the middle section"
4. Fourth prompt: "Add text overlay 'Summer 2024' at the beginning"

## What NOT to Do

❌ "Make it good"
✅ "Add dynamic pacing with cuts every 3-5 seconds"

❌ "Edit this"
✅ "Create a 45-second highlight reel with the most exciting moments"

❌ "Fix it"
✅ "Reduce the intro to 5 seconds and tighten the transitions"

Experiment with these prompts and create your own! The AI learns from detailed, specific instructions.
